# すわりぺん（仮）

座ったまま、なすがまま。iPhone向け・一投勝負のスワイプゲーム。

プレイ: https://s2r-o.github.io/suwari-penguin/?v=10

## v0.10: 30コース、はじめのおはなし、おきがえ、音

v0.9の一投制と承認済みの見た目を土台に、保留だったオープニング、追加10コース、魚によるスキン解放、BGMと効果音を実装。

### オープニング

「ひと滑り、してみる」で、約19秒・6場面のドットアニメーションを初回に再生。師匠の腹すべりの見本、聞いていない弟子、魚への反応、師匠の工事、ごほうびの配置、座ったままの主人公からゲームへつながる。動画ファイルを外部配信せず、既存のCanvasとキャラ素材で動かす短編。建設時の音も鳴る。

いつでもスキップ可能。一度見た後は再生せず、タイトルの「はじめのおはなし」から見直せる。端末の「動きを減らす」設定では各場面の動きを抑える。

### 全30コース、すべて一投

01〜20の地形・物理は維持。21〜30は雪、反射、先輩ペンギン、釣り針、川越えを組み合わせた追加コース。コース選択は1〜10、11〜20、21〜30のタブで切り替え、どの面からでも試せる。

26「一息で、ふたつの川。」では一投で二度の川越え。29「最後の、ひとつ手前。」は反射と針の通過時刻。30「師匠、やりすぎ。」は二つの川、雪、氷壁、横切る先輩、三本の釣り針を一投で抜ける最終試験。ジャンプ台は幅広のままで、自動照準はない。

全30コースに一投でクリアできる経路を演算とブラウザの実際の更新処理で確認。ただし人の指での難易度、特に最終面の難しさは未確定であり、実機で調整する。

### 魚で着替える

初クリアごとに魚3匹。前のバージョンでクリアした面も、同じブラウザに保存された記録から一度だけ遡って付与する。同じ面の再クリアで重複付与はしない。

タイトルまたはコース選択の「おきがえ」から交換・装備できる。標準を含め7種類。いつもの姿、夜ふかし、ぶどうあいす、ミントミルク、師匠のおさがり、おひるね係、30面クリア限定の「免許皆眠」。魚を使うのは初回交換だけで、持っている服への着替えは無料。

スキンは見た目のみ。指追従、速度、摩擦、ジャンプ、当たり判定は共通。師匠にはプレイヤーの着替えを適用しない。

### BGMと効果音

Web Audioによるオリジナルの音源。のんきな通常曲と後半コース向けの曲を切り替え、メロディー・低音・和音を重ねる。氷と雪の滑走音、壁、ジャンプ、着地、釣り上げ、着水、工事、魚獲得・着替え交換に効果音を入れた。

最初のボタン操作で音を開始。BGMと効果音を個別にオン・オフでき、音量を保存する。「音・設定」またはプレイ画面の音ボタンから変更できる。音が止まった場合の「音を再開・試聴」も用意。非表示時には停止する。

## 維持した仕様

主人公は怠け者で鈍臭い。師匠がコースを作り、本人は座ったまま魚を目指す。指への即時追従とリリース速度、ガイド線なし、テイクバックの要求なし、一投制を維持。物理演算は固定120Hz、氷の摩擦90、雪の倍率1.4、壁の反発係数0.80を変更していない。

承認済みの標準キャラスプライト、空中のばたばた、落水後のぷかぷか、釣り竿と糸の接続、ゴールからスタートへのコース紹介、慣性スクロール、ミニマップも維持。

## 保存・費用・構成

保存はこのブラウザのlocalStorageのみ。クリア記録を消さず、魚・服・音の設定を別キーへ保存。ブラウザデータ削除や別の端末・ブラウザへの切り替えでは引き継がれない。保存できない場合は着替え画面で表示する。

`index.html` は入力・物理・キャラ・基本画面、`world.js` は従来のギミックと描画（v0.9から変更なし）、`courses.js` は21〜30、`extras.js` は物語・着替え・魚・音、`extras.css` は追加画面。

ゲームに追加パッケージ、外部素材配信、バックエンド、アカウント、解析タグ、有料APIは使わない。既存GitHub Pagesで配信する。ネイティブアプリ化やApp Store配信は含まない。

## 検証と残る確認

`node tests/v10.cjs` で従来の物理・演出検証（540+336）と一投制、追加150アサーションが成功。魚の遡及付与・重複防止・交換・保存読戻し・音の設定・保存不能時・30面の一投到達を含む。最終面は成功経路付近の27条件でも到達を確認したが、これは人間の成功率ではない。

Chromiumの390×844・タッチ相当の画面で191チェックが成功。オープニング全6場面、スキップと再視聴、30面すべての実更新による一投クリア、魚加算、7スキン、交換と再装備、追加投擲の拒否、指追従、結果・リトライ、保存読戻し、音の個別設定を確認。実際のWeb Audio処理で曲の進行と非ゼロの音声サンプル、ミュート後の無音を確認。320・430幅の横はみ出しも確認した。

ブラウザ検証はローカルソースをDOMに読み込む方式。永続化は明示したStorageテスト用実装での読戻し確認であり、iPhone実機・Safariでの検証ではない。iPhoneでの音量・復帰動作・親指の操作感・難易度調整は引き続き確認が必要。機能の追加完了と、製品品質の最終確認を区別する。
