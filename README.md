# すわりぺん（仮）

座ったまま、なすがまま。iPhone向けの縦長コース式スワイプゲーム。

プレイ: https://s2r-o.github.io/suwari-penguin/?v=09

## v0.9: 全コース、一投勝負

すべてのコースでスワイプは一度だけ。指に追従するペンギンを離し、その一投だけで魚へ触れればクリア。途中で止まったら失敗として即リトライできる。移動中も停止後も追加の一投はできない。単なるタップは消費せず、微小な指ぶれも無料の前進に使えない。動かしてから静止した状態で離す場合は一投を使う。

既存20コースの地形、摩擦、川幅、ジャンプ計算、釣り糸、落水演出、スプライトと基本UIは維持。一投制の全体ルール、二投前提のヒントと表示を変更した。既存のクリア記録は消さずに残す。30面への拡張、オープニング、魚によるスキン解放、BGMは今回の変更には含まない。

## 世界観と操作

主人公は怠け者で鈍臭いペンギン。修行はしたくないが魚は欲しい。師匠が手作りの練習場を建設して、ご褒美の魚を置く。上達するのはプレイヤーで、本人は最後まで座ったまま。

触れた瞬間から指に追従し、離した直前の速度と方向を引き継ぐ。引っぱり発射、テイクバックの要求、狙いのガイド線はない。滑走距離に応じた摩擦仕事で減速し、壁では法線方向の速度が減衰する。身体の回転や焦る演技は進路をランダムに変えない。

新ステージはゴールからスタートへの紹介カメラ。タップでスキップでき、リトライには挟まない。背景の2.5倍慣性スクロール、ミニマップ、全体表示、ペンギンへ戻る機能を維持。

## 構成と公開

- `index.html`: 指追従、固定120Hz物理、一投制、基本8コース、キャラとUI。
- `world.js`: 追加12コース、ジャンプ、先輩、針、落水、世界の描画。
- `.github/workflows/pages.yml`: 既存のmain更新からGitHub Pagesへ公開。変更なし。

追加パッケージ、バックエンド、外部API、有料サービス、解析タグは使用しない。進行記録は端末内のlocalStorageのみ。

## 検証

`node tests/v09.cjs` で既存の物理・演出876アサーションと全20コースの一投制を検証できる。20コースすべてに一度の発射から到達する経路を確認。Chromiumの390×844タッチ相当環境でも、全20コースの一投クリア、停止後・移動中の追加発射拒否、タップ、指追従、静止後のリリース、リトライ、20面選択など134項目を再確認した。

これはiPhone実機の操作感や難易度が完成したという意味ではない。今回の目的は一投制を実際に触って評価すること。

旧版の仕様と検証記録は [docs/history-v08.md](docs/history-v08.md) に保存。そこにある二投制の記載は旧仕様であり、v0.9には適用しない。
