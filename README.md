# すわりぺん（仮）

座ったまま、なすがまま。iPhone向けの縦長コース式スワイプゲーム。

プレイ: https://s2r-o.github.io/suwari-penguin/?v=08

## 世界観と維持する仕様

主人公は怠け者で鈍臭いペンギン。修行はしたくないが、魚は欲しい。師匠が手作りの練習場を建設して、遠くにご褒美の魚を置く。上達するのはプレイヤーで、本人は最後まで座ったまま。冒頭の建設ムービーは保留で、実装していない。

承認済みの主人公スプライト、浮き輪、師匠、雪、魚の皿、基本画面を維持。ペンギンは触れた指に追従し、離した直前の速度と方向で滑る。テイクバックの要求、引っぱり発射、狙いのガイド線、ジャンプボタンはない。身体の回転は進路をランダムに変えない。

新ステージはゴールからスタートへ紹介カメラ。タップでスキップ、リトライでは再生しない。背景の2.5倍慣性スクロール、ミニマップ、全体表示、ペンギンへ戻る機能も維持している。

## v0.8: ぽちゃん、そのあとはぷかぷか

落水時は、座った姿で小さくばたついて沈み、泡だけが残る短い間を挟んで顔が戻る。その後は落ち着いてまばたきしながら水面で上下する。身体を縮めて消す表現と、突然出現する落水用浮き輪を廃止し、水面で身体を隠す描画にした。開始地点の浮き輪は変更していない。

演出は約2.15秒。途中でも既存の「もう一度」からすぐやり直せる。動きを減らす端末設定では静止した浮き姿を表示し、従来と同じ1.05秒で結果へ進む。結果は「浮くほうが、楽でした。」。落水は引き続き失敗であり、復活・救済ルールは追加していない。

川の寸法、全20コース、指追従、摩擦、ジャンプ計算、釣り糸の接続、地上・空中の既存スプライトは変更していない。新規依存やサービスもない。変更は失敗時の表示と待ち時間、および表示用の落水位置の記録に限定している。

`node tests/v08.cjs` で既存回帰540件と水面演出336件に成功。5つの川の左右岸、沈む・泡・再浮上・浮遊の段階、表示による物理状態の非変更、固定サイズ、水面での下半身の隠れ方、リトライ時の解除を確認。既存の20コース到達と釣り糸8本の検証も含む。

Chromiumの390×844モバイル相当表示で34件を確認。通常と動きを減らす設定、実際のゲーム更新からの落水、結果の表示時刻、演出途中のリトライ、ステージ選択、通常コースのクリア、JavaScriptエラーなしを確認し、落水の実描画動画を記録した。ローカルソースをメモリ内に読み込んだ検証で、iPhone実機・Safariは未検証。

以下はv0.7の仕様と検証の記録。現行の回帰検証は `node tests/v08.cjs` を使用する。

## v0.7: 川越えの調整と、空中・釣り上げの演出

### 川は少し長く、台は広いまま

川越えのある09・12・14・17・20は、幅308のジャンプ台と2打制を維持。台の入口を狭くせず、川の対岸だけを遠ざけた。川の進行方向の長さはそれぞれ200・200・210・220・230ワールドピクセル（v0.6では145・135・150・160・160）。通常の氷、雪、壁の減衰、台の傾斜、ジャンプの物理式は変更していない。

川だけを切り出した正面進入の数値検証では、必要な進入速度がv0.6比で約14〜17%上昇した。これはゲーム全体の難易度を百分率で表したものではない。十分な勢いなら斜めに飛べる余裕を残し、弱い進入は対岸へ届かない。自動照準や台での加速は入れない。

### 座ったまま、空中でばたばた

空中のみ、左右のヒレを振り、足を交互にばたつかせる4コマを追加。驚いた目、開いたくちばし、小さな汗を合わせ、座った胴体と16方向の向きを維持する。着地すると従来の姿へ戻る。アニメーションは飛距離や当たり判定に影響しない。動きを減らす端末設定では静止した驚きポーズを使う。

地上の通常・まばたきスプライト32枚は、v0.6とピクセル一致を検証した。主人公の顔、色、輪郭や基本UIを別デザインへ作り直していない。

### 竿・糸・針・主人公を一本につなぐ

針に触れた瞬間に、捕まえた釣り人の番号と竿先、主人公の位置を保存する。引き上げ中の本体位置と針の接点を同じ計算で決め、その接点へ竿先から一本の糸を描く。捕まえた釣り人の通常のぶら下がり針は非表示にし、独立した二本目の糸を描かない。左右どちらの釣り人でも同じ処理を使い、リトライ時に捕獲情報を解除する。

## 維持した遊びと構成

全20コース。川越えは5コースに限定し、それぞれ2打。既存のクリア記録の番号を維持する。通常の氷の摩擦90、雪の摩擦仕事倍率1.4、壁の法線方向の反発係数0.80はv0.6から変更していない。雪や壁で勢いを失い、川までのルートが飛距離に影響する。

`index.html` は入力・固定120Hz物理・既存8コース・スプライト・UI、`world.js` は追加12コース・ジャンプ・先輩・釣り針・世界の描画。追加パッケージ、バックエンド、外部API、解析タグは不要。進行記録は端末内のlocalStorage。既存のGitHub Pagesワークフローで配備する。

## v0.7検証記録

`node tests/v07.cjs` は実際に配信するHTML内の物理コードとworld.jsを読み込み、540のアサーションに成功。125条件の川越え（左右5位置×進入角5種類×5コース）、全20コースの規定打数内到達経路、全8本の針での捕獲と接続位置を含む。川越えの125条件は、壁・雪・移動障害物を除いた台と川の単体検証であり、どんなルートでも成功することを保証しない。

別途、Chromium 144のモバイル相当画面で21項目を確認。地上の32スプライト一致、空中4コマの違い、指追従、リリース速度、打数、紹介カメラ、全体表示、左右の釣り人の引き上げ描画、リトライ、20コース選択、JavaScriptエラーがないことを含む。

ブラウザ検証はローカルのHTML・JavaScriptをメモリに読み込んだもの。iPhone実機・Safari・実際の親指の感触は未検証。到達経路の存在は、難易度や操作感の完成を意味しない。`tests/v06.cjs` は前版の記録であり、現行の回帰検証には `tests/v07.cjs` を使用する。
