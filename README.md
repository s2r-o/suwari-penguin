# すわりぺん（仮）

座ったまま、なすがまま。iPhone向けの縦長コース式スワイプゲーム。

プレイ: https://s2r-o.github.io/suwari-penguin/?v=06

## 世界観と維持する仕様

主人公は怠け者で鈍臭いペンギン。修行はしたくないが、魚は欲しい。師匠が手作りの練習場を建設して、遠くにご褒美の魚を置く。上達するのはプレイヤーで、本人は最後まで座ったまま。冒頭の建設ムービーは保留で、実装していない。

承認済みの主人公スプライト、浮き輪、師匠、雪、魚の皿、基本画面を維持。ペンギンは触れた指に追従し、離した直前の速度と方向で滑る。テイクバックの要求、引っぱり発射、狙いのガイド線、ジャンプボタンはない。身体の回転は進路をランダムに変えない。

新ステージはゴールからスタートへ紹介カメラ。タップでスキップ、リトライでは再生しない。背景の2.5倍慣性スクロール、ミニマップ、全体表示、ペンギンへ戻る機能も維持している。

## v0.6: 勢いを残して、川の向こうへ

- 全20コース。01〜08の地形と既存のクリア記録の番号は維持し、15〜20を追加した。
- 通常の氷の摩擦は90のまま。雪の摩擦仕事を従来の1.4倍にした。同じ距離でも雪ではより大きく減速する。
- 壁の法線方向の反発係数は0.90から0.80へ。正面衝突後は速度80%、運動エネルギー64%が残る。壁に沿う速度成分は変えない。
- ジャンプ台は従来108〜116から308ワールドピクセルに広げた。中央に当てる必要はなく、左右から斜めに入ってよい。自動照準、直線への方向補正、台での加速はしない。
- 川の手前に広い助走台、向こう岸に広い着地スペースを配置。台の直後に針や先輩を置かず、着地してから考える余裕を設けた。
- 川を越えるコースは09・12・14・17・20の5つで、いずれも2打。必ず1打で魚まで一直線に狙う必要はない。
- 雪の近道と氷の迂回路、壁を避ける左右の助走路など、ジャンプ前の経路が残る速度に影響する。
- ジャンプの飛距離は進入速度と26度の台の傾斜から計算する。摩擦や衝突で勢いを失いすぎると川に落ちる。

## 構成と検証

`index.html` は入力・固定120Hz物理・既存8コース・UI、`world.js` は追加12コース・ジャンプ・先輩・釣り針・世界の描画。追加パッケージ、バックエンド、外部API、解析タグは不要。進行記録は端末内のlocalStorage。既存のGitHub Pagesワークフローで配備する。

v0.6のローカル検証では物理・回帰72チェック、Chromiumのモバイル相当表示・入力/UI45チェックを通過。5つのジャンプコースについて、障害物と雪を取り除いた助走・川・着地単体を、左右5位置×角度5種類（−25、−15、0、15、25度）の125条件で確認した。十分な初速なら全条件で越え、弱い初速では川に落ちる。これは全コースの全入力で成功するという意味ではない。

20コースすべてに120Hzの実装と同じ演算で規定打数内の到達経路を確認。指追従・速度推定・カメラの処理、承認済み主人公スプライトはv0.5と同一。ブラウザ検証はローカルソースをメモリ内に読み込んだものであり、iPhone実機・Safari・実際の親指の感触の検証ではない。難易度と操作感が完成したことも意味しない。

`node tests/v06.cjs` で主要な減衰・ジャンプの角度許容・20コース到達の回帰検証を再実行できる。
