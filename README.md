# すわりぺん（仮）

座ったまま、なすがまま。iPhone向けの縦長コース式スワイプゲーム。

プレイ: https://s2r-o.github.io/suwari-penguin/?v=05

## 世界観

主人公は怠け者で鈍臭いペンギン。腹すべりの修行はしたくないが、魚は欲しい。師匠が手作りの練習コースを建設して、遠くにご褒美の魚を置いている。上達するのはプレイヤーで、主人公は最後まで座ったまま。

師匠がコースを建設する冒頭ムービーは企画として保留。v0.5には実装していない。

## 操作と維持する仕様

- ペンギンを触って動かすと、その場で指に追従。離した直前の速度・方向を引き継いで滑る。
- テイクバック不要。引っぱり発射、狙いのガイド線、ジャンプボタンはない。
- 氷上は移動距離に対する摩擦仕事で減速。壁は法線方向の反発係数で減衰。身体の回転は進路をランダムに変えない。
- 長いコースを1〜2打で攻略し、魚に接触するとクリア。
- 新ステージではゴールからスタートへの紹介カメラ。タップでスキップ。リトライでは再生しない。
- 背景は2.5倍の慣性スクロール。右のミニマップ、コース全体表示、ペンギンへ戻る操作も利用できる。
- 最初の承認動画の主人公スプライトと基本画面を維持する。別デザインへの作り直しは禁止。

## v0.5: 師匠の手づくり修行場

既存の8コースは変更せず、追加6コースで合計14コース。タイトルの「コースを選ぶ」から全コースへ直接進める。

| コース | 内容 |
| --- | --- |
| 09 師匠、橋は？ | 木製ジャンプ台と大きな割れ目。進入の勢いで飛距離が変わる。 |
| 10 先輩、お先に。 | 周期的に横切る腹すべりペンギン。接触は即失敗ではなく衝突による押し出し。 |
| 11 おさかな、じゃない。 | 揺れて上下する釣り針。捕まると座ったまま持ち上げられる。 |
| 12 空中でも、座ったまま。 | ジャンプと横切る先輩を組み合わせる。 |
| 13 雪で、ひとやすみ。 | 雪・氷壁・釣り針。止まる場所と次の一打。 |
| 14 師匠の力作。 | ジャンプ、割れ目、先輩、釣り針を組み合わせたコース。 |

雪は凹凸・積雪・光・通過時の粉雪で表現。スタートは浮き輪。師匠、練習看板、足跡、旗、ご褒美の皿と魚バケツを追加。操作に影響するものと背景小物を区別している。

## 構成・配備

- `index.html`: 従来の操作、固定刻みの氷物理、既存8コース、承認済みスプライト、画面とカメラ。
- `world.js`: 追加6コース、ジャンプ・移動体・釣り針、世界観の描画。
- `.github/workflows/pages.yml`: mainへのpushからGitHub Pagesへ配備。

ビルドや追加パッケージは不要。2ファイルを同じディレクトリからHTTP配信する。バックエンド、外部API、解析タグ、新しい有料サービスは使用しない。進行記録は端末のlocalStorage内のみ。

## 検証記録

v0.5配備前に、物理・ギミック41項目、Chromiumのモバイル相当タッチ/UI36項目が成功。14コースすべてについて120Hzの実装と同じ刻みで規定打数以内の到達経路を確認。

検証内容には指追従、離した瞬間の速度、静止後の誤発射防止、衝突、距離による停止、ジャンプの飛距離、空中通過、穴・針の失敗、周期とリトライの再現、開始カメラ、慣性スクロール、ステージ選択を含む。

ブラウザ検証はメモリ上に読み込んだHTML/JavaScriptによるもの。iPhone実機・Safari・実際の指での感触は未検証。経路が存在することは難易度調整や操作感が完成したことを意味しない。調整時は既存の指追従モデルと承認済みアートを維持する。
