# すわりぺん（仮）

座ったまま、なすがまま。iPhone向け・全30コース一投勝負のスワイプゲーム。

プレイ: https://s2r-o.github.io/suwari-penguin/?v=12

## v0.12: 大きく飛ぶ楽しさと、1-1の小さな案内

### 飛び越えは攻略として許す

v0.11の対岸70ワールドピクセル先へ着地させる制限を取り除いた。26度の台へ入った速度から放物線を決める。勢いが大きいほど高く、遠くへ飛び、下の雪や壁、先輩などを飛び越えてよい。途中で速度を切ったり、強制的に着地させたり、自動照準したりしない。弱いジャンプは引き続き川に落ちる。

極端に高いジャンプで、実際のコース外周まで飛び出したときだけ場外として失敗する。速度だけで即失敗にしない。画面やカメラの端ではなく、ワールド上の外周で判定する。地上と通常の高さのジャンプは従来どおり端で反射する。

現在の外周越え条件は高さ300超。これはゲーム用の調整値であり、通常の斜めジャンプを罰しないために高くしている。場外時は座ったままばたついて飛んでいき、「師匠、飛びすぎました。」と表示。すぐリトライできる。

### 1-1だけ、言葉を少なく

最初のコース（01）では、紹介カメラでお魚を見せて「おさかなへ。」。スタートへ戻ると、ペンギンに触れて払う指の見本と「つかんで、スッ。」を表示する。

触れたら見本は消え、本人の指にそのまま追従。「はなすと、すべる。」と伝え、リリース後はお魚へ向かう。下部には「おさかなに触れたらクリア」の一文だけ。説明用のダイアログ、自動発射、狙いのガイド線、テイクバックの要求は追加していない。

案内は01だけに表示し、後のコースには出さない。背景を見回している間も指の見本は表示しない。端末の動きを減らす設定では指の見本を静止表示する。

## 維持した内容

全30コースの地形、全ステージ一投制、指への追従とリリース速度、氷・雪・壁の摩擦、標準キャラと空中のばたばた、釣り糸接続、落水のぷかぷか、6枚のセリフなし紙芝居、魚での7種類の着替え、BGM・効果音・保存処理を維持。既存セーブは消さない。

追加の実行時パッケージ、常駐処理、外部API、バックエンド、解析タグ、有料サービスはない。既存のGitHub Pagesで配信する。

## 検証

`node tests/v12.cjs` を公開前にも実行する。従来のv07〜v10の回帰検証に加え、自然な飛距離、通常ジャンプ297条件で場外にならないこと、強いジャンプによる障害物の飛び越し、実際の外周通過による失敗、空中にいるだけでは失敗しないこと、地上の反射、リトライと表示状態の非干渉を確認。全30コースに一投クリアの到達経路がある。

Chromiumの390×844、375×667相当画面で30項目を確認。指追従には模擬タッチ、速度とリリースには時刻を管理したPointerEventを使用。案内から実際の一投クリア、場外から結果画面、途中リトライ、30面と7スキン、短い案内と動きを減らす設定を確認した。元の地上物理とキャラ描画関数はv0.11から不変。

ブラウザ検証はローカルソースをメモリ内で実行したもの。iPhone実機・Safari・人間の親指の感触は未検証。経路の存在は難易度調整の完成を意味しない。音源は変更せず、今回は音をミュートして画面と入力を検証した。現行テストはv12を使用し、着地制限を検証する旧v11は旧仕様の記録とする。
